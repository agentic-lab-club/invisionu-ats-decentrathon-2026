# 🏆 TalantParser

**Интеллектуальный агрегатор новостей о победах казахстанских школьников и студентов колледжей.**

Система автоматически парсит новости из 6 источников (Daryn.kz, Tengrinews, МОН РК, Inform.kz, Bilim.kz, Kazpravda), извлекает имена победителей и фильтрует релевантный контент. На выходе получается структурированный JSON с информацией о каждой победе.

## 🔌 API Endpoints

### 1️⃣ **GET** `/` - Получить все новости
Возвращает кэшированный список всех релевантных новостей.

**Параметры:**
- `source` (optional) — фильтр по источнику, например `Daryn.kz`
- `query` (optional) — поиск по заголовку или `winner_info`

**Пример запроса:**
```http
GET http://localhost:9432/
Accept: application/json
```

**Пример ответа:**
```json
[
  {
    "title": "200 школьников стали победителями Республиканской олимпиады...",
    "link": "https://daryn.kz/blog/2025/11/29/...",
    "source": "Daryn.kz",
    "high_school_student_name": "Имран Кусанов",
    "date": "29.11.2025",
    "winner_info": "олимпиады» награжден семиклассник..."
  },
  {
    "title": "Школьник из Семея, серебряный призер...",
    "link": "https://daryn.kz/blog/2025/08/11/...",
    "source": "Daryn.kz",
    "high_school_student_name": "Аскар Акежан",
    "date": "11.08.2025",
    "winner_info": "серебряный призер международной олимпиады по информатике..."
  }
]
```

**Фильтрация по источнику:**
```http
GET http://localhost:9432/?source=Daryn.kz
```

**Полнотекстовый поиск:**
```http
GET http://localhost:9432/?query=олимпиада
```

### 2️⃣ **POST** `/refresh` - Принудительное обновление кэша
Запускает немедленный парсинг всех источников (может занять 2-5 минут).

**Пример запроса:**
```http

```

**Пример ответа:**

    "error": null

  {
    "name": "Tengrinews",
    "base_url": "https://tengrinews.kz/educationscience/",
    "status": "ok",
    "http_code": 200,
    "items_found": 28,
    "last_checked": "2025-04-05T14:23:50.123456+00:00",
    "error": null
  },
  {
    "name": "МОН РК",

- `"pending"` — ещё не был обработан

## ⚙️ Конфигурация

Главные параметры в `Config`:

```python
refresh_interval: int = 24 * 3600        # Обновление кэша каждые 24 часа
concurrency_per_source: int = 4          # 4 одновременных HTTP-запроса на источник
request_timeout: int = 20                # Таймаут 20 секунд на запрос
winner_info_max_len: int = 200           # Максимум 200 символов в winner_info
use_playwright_fallback: bool = True     # Использовать Playwright для JS-сайтов
```

## 📋 Структура данных

### NewsItem (выходной JSON)

| Поле | Тип | Описание |
|------|-----|---------|
| `title` | str | Заголовок новости |
| `link` | str | Прямая ссылка на статью |
| `source` | str | Источник (Daryn.kz, Tengrinews и т.д.) |
| `high_school_student_name` | str\|null | Имя найденного победителя |
| `date` | str\|null | Дата публикации (29.11.2025 или 2025-11-29) |
| `winner_info` | str | Контекст победы (130-200 символов) |

### CacheStatus (статус кэша)

| Поле | Тип | Описание |
|------|-----|---------|
| `updated_at_utc` | str\|null | ISO timestamp последнего обновления |
| `total` | int | Количество новостей в кэше |
| `sources_scraped` | list[str] | Список источников в последнем цикле |

### SourceStatus (статус источника)

| Поле | Тип | Описание |
|------|-----|---------|
| `name` | str | Название источника |
| `base_url` | str | Корневой URL источника |
| `status` | str | ok \| empty \| error \| pending |
| `http_code` | int\|null | HTTP-код последнего запроса |
| `items_found` | int | Новостей найдено в последнем цикле |
| `last_checked` | str\|null | ISO timestamp последней проверки |
| `error` | str\|null | Текст ошибки (если есть) |

## 🔍 Как работает фильтрация

### Ключевые слова ПОБЕДЫ:
```
победител, призёр, призер, занял, заняла, завоевал, завоевала,
золот, серебр, бронз, медаль, наградил, награжд, чемпион,
выиграл, выиграла, обладатель, лауреат, первое место, второе место,
третье место, гран-при, гран при
```

### Ключевые слова ШКОЛЬНИКА:
```
школьник, школьников, школьниц, школьная, ученик, ученица, учеников,
учащихся, учащийся, колледж, колледжа, колледже, студент колледж,
воспитанник, воспитанниц
```

### Логика фильтрации:
```
Статья РЕЛЕВАНТНА, если:
  (содержит ХОТЯ БЫ ОДНО слово ПОБЕДЫ)  И  (содержит ХОТЯ БЫ ОДНО слово ШКОЛЬНИКА)
```

Пример:
- ✅ "Школьник **Иван** стал **призёром** олимпиады" — ПОДХОДИТ
- ❌ "Студент ВУЗа **завоевал** грант" — НЕ ПОДХОДИТ (нет школьника/колледжа)
- ❌ "Школьники **участвовали** в конкурсе" — НЕ ПОДХОДИТ (нет победы)

## 🔄 Алгоритм извлечения имён

Система использует 6 регулярных выражений для извлечения русских имён:

1. **"победитель Иван Иванов"** — явное упоминание
2. **"Иван Иванов завоевал золото"** — действие + достижение
3. **"наградили Ивана Иванова"** — пассивный залог
4. **"Иван Иванов — золото"** — тире-разделитель
5. **"школьник Иван Иванов"** — профессия + имя
6. **"Иван Иванов из [города]"** — географический контекст

Используется формат:
```regex
[А-ЯЁ][а-яё]{1,20}\s+[А-ЯЁ][а-яё]{1,20}(?:\s+[А-ЯЁ][а-яё]{1,20})?
```
(Имя + Фамилия или Фамилия + Имя + Отчество)

## 🎭 Playwright fallback

Для некоторых сайтов контент генерируется JavaScript. Система автоматически:

1. Пробует быструю загрузку через `httpx`
2. Если страница < 2000 символов → Playwright
3. Если источник имеет `needs_js=True` → сразу Playwright
4. Если Playwright недоступен → используется исходный HTML

Требует: `pip install playwright && playwright install chromium`
